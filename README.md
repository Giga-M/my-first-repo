# my-first-repo

## PC Info Tool (`PC-Info.bat`)

ინტერაქტიული CMD სკრიპტი Windows 10 / 11-ისთვის. აჩვენებს კომპიუტერის
კომპონენტებსა და სისტემის მნიშვნელოვან პარამეტრებს და ქმნის სრულ რეპორტს.

სკრიპტი **მხოლოდ კითხულობს** ინფორმაციას და სისტემაში არაფერს ცვლის.

### გაშვება

1. ჩამოტვირთეთ `PC-Info.bat`.
2. გაუშვით ორჯერ დაწკაპუნებით.
3. დამატებითი ინფორმაციისთვის (TPM, BitLocker, დისკის ტემპერატურა და ცვეთა,
   ბატარეის სიმძლავრე) მენიუში აირჩიეთ **[U]** ან გაუშვით
   „Run as administrator“-ით.

### მენიუ

| ღილაკი | განყოფილება | რას აჩვენებს |
|---|---|---|
| 1 | Processor (CPU) | მოდელი, ბირთვები/ნაკადები, სიხშირე, ქეში, სოკეტი, დატვირთვა, ვირტუალიზაცია |
| 2 | Memory (RAM) | სულ/გამოყენებული, ტიპი (DDR4/DDR5), სლოტები, თითოეული მოდული: ზომა, სიჩქარე, მწარმოებელი |
| 3 | Graphics (GPU) | ვიდეობარათი, VRAM, დრაივერის ვერსია/თარიღი, გარჩევადობა, მონიტორები და მათი ზომა |
| 4 | Motherboard and BIOS | დედაპლატა, BIOS-ის ვერსია და თარიღი, UEFI / Secure Boot |
| 5 | Storage | დისკები (SSD/HDD, NVMe/SATA, ჯანმრთელობა), დანაყოფები და თავისუფალი ადგილი |
| 6 | Battery | დამუხტვა, სტატუსი, ბატარეის „ჯანმრთელობა“ (ლეპტოპებზე) |
| 7 | System overview | Windows-ის ვერსია, build, აქტივაცია, uptime, მოდელი |
| 8 | Network | ადაპტერები, IP, MAC, gateway, DNS, Wi-Fi ქსელი, ინტერნეტი |
| 9 | Security status | ანტივირუსი, Firewall, UAC, Secure Boot, TPM, BitLocker, განახლებები, SMBv1, RDP |
| A | Performance | CPU/RAM დატვირთვა ახლა, 10 ყველაზე „მძიმე“ პროცესი |
| B | Programs | დაინსტალირებული პროგრამები, ავტოჩატვირთვა |
| C | Devices | Device Manager-ის პრობლემური მოწყობილობები, აუდიო, კამერები |
| R | **Report** | სრული რეპორტი HTML + TXT ფორმატში |

### რეპორტი

რეპორტი ინახება აქ: `Desktop\PC-Reports\PC-Report_<კომპიუტერი>_<თარიღი>.html` (და `.txt`).
თავში არის მოკლე შეჯამება და სია „Needs attention“: ყველაფერი, რასაც ყურადღება სჭირდება
(მაგ. დისკზე ცოტა ადგილია, Firewall გამორთულია, მოწყობილობას დრაივერი აკლია).

### როგორ მუშაობს

მენიუ დაწერილია CMD-ზე. მონაცემებს აგროვებს PowerShell-ის კოდი, რომელიც იმავე
ფაილის ბოლოშია (`#PS-CODE#`-ის შემდეგ). ამიტომ საკმარისია ერთი ფაილი.
ძველი `wmic` არ გამოიყენება, რადგან Windows 11-ის ახალ ვერსიებში ის ამოღებულია.
